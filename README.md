# PID 控制自走車轉速專案

這個專案使用 PID 控制算法來調節自走車的電機轉速，並且利用編碼器來監測轉速。該程式能根據編碼器的脈衝數來計算當前轉速，並將其與目標轉速進行比較，通過 PID 演算法調整電機的輸出來維持穩定的轉速。

## 硬體需求

- **Arduino 開發板**（如 Arduino Uno、Mega 等）
- **直流電機**（與 Arduino 配合使用）
- **H橋馬達驅動模組**（如 L298N）
- **編碼器**（例如增量式編碼器）
- **電源**（適合電機的電壓）

## 引腳配置

| 引腳          | 描述          |
| ------------- | ------------- |
| `encoderPin`  | 連接編碼器的數字輸入引腳（用來讀取脈衝信號） |
| `motorPin1`   | 控制電機正向轉動的引腳 |
| `motorPin2`   | 控制電機反向轉動的引腳 |
| `pwmPin`      | 控制電機速度的PWM引腳（0-255） |

## 軟體需求

- Arduino IDE
- PID_v1 庫（用於 PID 控制算法）

## 安裝 PID_v1

在 Arduino IDE 中，請按以下步驟安裝 PID_v1 庫：

1. 打開 Arduino IDE。
2. 點擊 **工具** > **管理庫**。
3. 在庫管理器中搜尋 **PID_v1**。
4. 點擊安裝。

## 程式碼說明

### 主要程式結構

- **編碼器脈衝計算**：
  透過 `attachInterrupt` 函數來監測編碼器的脈衝，並計算轉速（RPM）。

- **PID 控制**：
  PID 控制器會將目標轉速（`setpoint`）與當前轉速（`input`）進行比較，根據誤差計算控制輸出（`output`）。控制輸出會用來調節電機的轉速。

- **控制電機**：
  透過 `analogWrite` 控制馬達的轉速，並根據 PID 輸出來決定電機的轉向（正向或反向）。

### 重要變數和函數

- `setpoint`：目標轉速（RPM）
- `input`：當前轉速（由編碼器計算）
- `output`：PID 控制輸出的結果
- `Kp`, `Ki`, `Kd`：PID 控制的三個常數，需根據實際情況進行調整
- `PID.Compute()`：計算 PID 控制輸出
